Kiosune font packer

Turns a pixel font (.ttf/.otf) or a glyph-sheet PNG into what Kiosune Studio's Import a bitmap font dialog asks for: a PNG grid of equal cells, the cell size, the baseline and the characters in cell order. Nothing to count by hand.

3 · In the text box

Kiosune's ADV box on the 480×270 canvas (298×64, the 62% dialogue width), drawn the way the studio lays out a bitmap font: each glyph trimmed to its ink, 1px apart, lines a cell apart. Padding (8px sides, 6px top) is an assumption.

4 · Check the order

Each cell with the character it was given. The orange line is the baseline. A sheet's order is a convention, so a wrong guess shows up as a whole run of shifted labels.

How the measurements are made
  1. Sheets: ink is every opaque pixel, or on an opaque sheet every pixel unlike the most common colour. The cell is the smallest width and height that divide the sheet and that no glyph straddles.
  2. Baseline is the number of pixel rows above the baseline: the bottom row most capitals and digits sit on. Kiosune's default 8×12 cell uses 10.
  3. Fonts: the pixel size is the period of the glyph edges in a large render, checked against the sizes that draw with no grey edge pixels. A glyph the font lacks (the browser would substitute another font) is left out and listed.
  4. Cell is the widest glyph by the tallest ascent plus the deepest descent, so every glyph fits.
